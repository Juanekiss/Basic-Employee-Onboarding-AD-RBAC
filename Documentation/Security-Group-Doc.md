# Security Group Documentation

## Domain
Domain name: NMG.com

## Organizational Units (OUs) Created
- Finance
- HR
- IT
- Operations

## Security Groups Created
- Finance-Users
- HR-Users
- IT-Users
- Operations-Users

## Purpose of Each OU
- *Finance*: Users working in the finance department
- *HR*: Users working in human resources
- *IT*: Users working in the IT department
- *Operations*: Users working in daily business operations

## RBAC Principle
Access is managed through security groups rather than individually per user. Users are added to the security group matching their department, inheriting all permissions associated with that group. This makes onboarding, offboarding, and auditing significantly faster and less error-prone.
